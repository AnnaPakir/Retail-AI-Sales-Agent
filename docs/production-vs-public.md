# Что перенесено из production, а что заменено

| Область | Исходный контур | Публичный репозиторий |
|---|---|---|
| Каналы | CRM Open Lines и мессенджеры | HTTP webhook в n8n |
| Оркестрация | большой n8n workflow | компактный adapter + Python core |
| Поиск | PostgreSQL FTS + pgvector | локальный воспроизводимый hybrid retrieval |
| Товары | сайт, цены и складские таблицы | синтетический JSON-каталог |
| Модели | основной и fallback LLM providers | OpenAI-compatible adapter + deterministic fallback |
| Медиа | изображения и асинхронная транскрипция audio | описано как внешний adapter, не эмулируется |
| Логи | ответы, tools, контекст | redacted in-memory execution traces |
| Передача | CRM operator handoff | действие `human_handoff` в API |

## Почему не опубликован исходный workflow

Даже после удаления очевидных ключей export может раскрыть названия таблиц, внутренние URL, идентификаторы CRM, служебные промпты и фрагменты персональных данных. Поэтому этот репозиторий собран заново по наблюдаемому поведению системы.

Такой подход сохраняет инженерные решения, но не превращает портфолио в утечку production-контура.
